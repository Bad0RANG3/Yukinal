# 团队上下文与工作页边界

本文记录当前实现。窗口布局见 [Windows 桌面窗口方向](./desktop-window-direction.md)，视觉规则见 [界面表达与皮肤约定](./ui-design-system.md)。

## 范围与持久化

| 数据 | 范围与用途 |
| --- | --- |
| 对话历史 | 会话绑定服务器；未选服务器时为全局会话。保存消息、参与者、模型和工具／审批事件 |
| 模型工作上下文 | 会话与上下文代次内的有界投影，不替代原始历史 |
| 显式记忆 | 全局或指定服务器；由用户保存、修改、删除，可跨该范围的会话引用 |
| 工作页 | 打开时捕获服务器 ID；后续服务器选择不改变已有页的目标 |

同一会话不能改绑到其他服务器。客户端按范围恢复会话视图与草稿，后端独立校验会话绑定。全局上下文不自动并入服务器对话；服务器对话可检索全局记忆和该服务器记忆，不能检索其他服务器的记忆。

桌面历史与 sidecar 的运行记录承担不同职责：前者用于浏览、恢复会话，后者保留模型轮次和结构化工具证据。旧会话可一次性导入已有用户／助手消息，不把旧系统提示重新当作当前策略执行。

## 角色与参与者

角色职责作为当前请求的 persona 系统提示，用户任务仍来自独立草稿。切换角色不注入或改写草稿；回复与运行记录保留实际参与者、Provider 和模型信息，同一对话的后续角色可以引用前轮证据。角色职责、历史摘录和记忆均不能替代工具审批。

参与者协议显式区分主角色与子参与者。子参与者需要已登记的父参与者，并受同一会话、服务器、上下文代次和深度限制约束。该协议提供身份与证据归属，不提供自主协作调度器，也不默认启动多模型并行。

## 有界上下文与重置

模型输入由当前策略与 persona、可检索的显式记忆、历史投影及当前用户输入组成。预算计入消息封装和工具定义，并预留后续运行空间；不使用固定的占用百分比表示未知模型窗口。

历史投影优先保留近期完整轮次；超出预算的早期轮次转为有界归档摘录。完整工具调用与结果保持轮次边界，不留下孤立结果。摘录保留来源角色、运行标识、状态及证据片段，并标为历史参考数据。它是确定性的归档摘录，不宣称由模型生成了完整语义总结。原始消息和审批／工具事件继续保留。

上下文重置递增会话代次并清除运行检查点；旧代次的运行标识不能重新写入新上下文。全部重置同时清空当前草稿和临时视图，保留对话历史、显式记忆、服务器与连接配置。存在运行中任务时拒绝重置。

## 显式记忆

记忆保存在本机 SQLite，FTS5 对生成的词项建立索引；查询词项作为绑定参数使用。没有 embedding、向量数据库或向量 RAG。模型请求在同一范围内检索匹配记忆，无词项命中时可引用少量最近保存的记忆，并受独立字节预算限制。

记忆以带来源的参考数据进入上下文，不提升为系统指令或授权。记忆库的全局／服务器范围直接对应后端读写校验；重置上下文不会删除记忆。

## 工作页与原生窗口

中央工作页复用文件、终端、日志和服务视图，四个固定标签不可关闭；“＋”新增的视图可以关闭。固定工具切换目标时，原目标视图降为普通页，保留其服务器绑定与已挂载的终端；新增终端使用独立会话 ID。证据页复用已有事件与产物数据。关闭视图不等于停止操作；中央终端在收起后保留 PTY，重开复用原会话。窄区域只展开一个页，输入框保持可用。

独立窗口与主窗口共享同一个原生 IPC router、数据库和事件来源，各 WebView 保留自己的订阅集合。文件、终端、日志和服务窗口通过已校验的类型和服务器 ID 打开；窗口地址不承载凭据或产物正文。独立终端新建 PTY，不接管中央终端。

独立窗口关闭时隐藏，主窗口退出时统一销毁。置顶使用 Windows topmost，失败返回结构化错误；界面收到成功结果后才更新状态。事件分发在关闭阶段受生命周期保护，避免向已销毁窗口交付回调。

产物只按显式且有界的 Markdown、图表、流程或 HTML 结构展示，未知内容回退为文本。Markdown 不执行原始 HTML。原生宿主保留 HTML 源码视图，禁用交互运行；顶层桥检查不能证明底层绑定在子框架内不可访问。无原生桥的浏览器 sandbox 预览不作为原生安全证明。

## 当前证据与待补项

真实 DeepSeek flash 请求使用产品角色提示，覆盖蓝队调用一次只读本机模拟工具、紫队与一个绿队子角色在同一对话复用前轮 marker 与数值，两者未重复调用工具。跨服务器复用被拒绝；重置后的模型上下文为空，三轮原始记录仍在。模型请求是真实的，工具数据来自本机模拟；未证明 SSH 连接、远程命令执行或自主多角色调度。
