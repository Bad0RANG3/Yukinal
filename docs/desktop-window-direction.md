# 桌面窗口与工作区

当前基线：`2.0.3`，2026-10-28。C++ WebView 宿主管理原生窗口，React 负责导航、主内容和参考信息。Windows 宿主在可执行文件中嵌入 Yukinal ICO，为主窗口及独立工作页显式设置大小图标和稳定 AppUserModelID。交互细则见[工作区交互说明](./workspace-tabs-spec.md)，共用样式见[界面表达与皮肤约定](./ui-design-system.md)。

## 窗口与标题栏

Windows 顶层窗口、缩放边缘及最小化/最大化/关闭由 Win32 与 DWM 管理。默认窗口 1440×900，最小原生窗口 1100×680；浏览器预览可检查更窄内容宽度。

支持标题栏融合的宽窗口把字标与工具行放入原生标题区域，空白支持拖动、系统菜单和双击最大化，按钮保留点击。系统按钮和顶部缩放边缘由宿主管理；紧凑窗口、不支持的运行时或同步失败使用独立标题栏。本轮未改变原生几何契约。

`WindowFrame` 从现有状态同步区域、目标、连接和忙碌状态；表面同步只传有界几何与颜色，不传凭据、提示词或授权。实现见[C++ 桌面宿主](./native-desktop-host.md)。

## 导航与主内容

左侧提供导航和服务器，中央承载对话或当前工具，右侧承载参考信息。文件、终端、日志、服务四按钮直接切换主界面，以按下状态表示选中工具；移除第二层标签、加号、分栏与返回对话操作。

Agent 在右侧浮栏继续对话；用户直接在主界面操作终端、文件。切换工具保留会话、目录、筛选和草稿；切换目标使当前工具跟随新服务器并保留旧终端。紧凑模式关闭参考信息后恢复工具。

旧团队角色、标签栏和独立窗口截图不作为当前导航规格。旧角色路由已在第五轮审计收尾清理；现有团队、值守按实际实现提供入口。验收确认不改变审批策略。

## 输入与适配

正文独立滚动，输入保持可见。浮栏附件、模型、设置、发送/停止同一行，控件 32px；Token/上下文控件 28px，展开不移动状态行。弹层按空间选择方向和尺寸，支持 Escape、外部关闭及合理焦点恢复。

参考信息显示真实目标、采集时间、资源、错误与缓存状态。能力来自检测，不从名称推断。紧凑布局按容器宽度重排，长值换行；代码与终端局部滚动。窄看板使用网格，浮栏为输入保留高度。

## 验证范围

今晚浏览器模拟覆盖 1381×1244、1024×768、390×844，连续检查切换、弹层、焦点与状态保留。自动回归见[发行记录](./release.md#发布验收)。这些结果不代替跨 DPI、Snap、独立窗口生命周期和三平台 GUI 拖放/升级覆盖。

负责人单独确认 Agent 能力合格并授权正式发布。历史原生截图和验证可从[AI 面板验证记录](./ai-panel-verification-20261017.md)及 Git 历史查阅。
