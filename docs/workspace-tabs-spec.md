# 工作区交互说明

更新：2026-10-27，适用于 `2.0.1`。保留旧文件路径兼容链接；原标签页设计已替换，历史可从 Git 查阅。

## 核心交互

工具栏固定提供 **文件、终端、日志、服务** 四按钮，点击直接切换中央主内容，同一时刻只显示一个工具。不再叠加标签条、加号菜单、左右停靠、分栏、展开或返回对话操作。

工具打开后，Agent 对话位于右侧浮栏，可继续交流；浮栏居中、拖动和缩放只调整对话位置。发送、停止和审批沿用既有执行链，视图切换不授予权限或停止运行。

| 操作 | 结果 |
| --- | --- |
| 点击四工具按钮 | 切换主界面，按钮以按下状态表示当前工具 |
| 未选目标时打开工具 | 提示选择服务器，选完后打开原先请求的工具 |
| 文件→终端→文件 | 保留目录与文件视图状态 |
| 离开并重开同一目标终端 | 保留原终端实例，不重复创建 PTY |
| 工具打开时切换服务器 | 当前工具跟随新目标，旧服务器终端保留并可恢复 |
| 切换工具/打开参考面板 | 保留草稿；紧凑模式关闭参考面板后恢复工具与目录 |
| 查看操作/产物证据 | 复用证据视图；记录按选中服务器过滤，证据可有自身标题和关闭操作 |

未绑定目标的工具显示明确选择提示。运行中切换目标遵守现有忙碌约束；导航不绕过审批与目标绑定。

## 状态与实现

`WorkpagesLauncher` 使用四个普通按钮与 `aria-pressed`，不声明标签页语义。`AppShell` 保存等待选择目标的工具类型；`WorkpagesDock` 与 `WorkspaceLayers` 负责单一可见主界面和 Agent 浮栏。

现有 store 按工具类型与服务器缓存页面，不在每次点击时追加重复页。非活动视图隐藏，`retainedTerminals` 保持终端实例；隐藏视图与结束远端操作分别处理。证据队列保留容量上限。

遗留 `WorkspaceTabStrip`、方向偏好与原生独立窗口底层实现未作为中央工作区入口；不能因旧状态字段存在而恢复第二层导航。本轮不改原生标题栏和后端契约。

## 用量与输入控件

- Token/上下文触发按钮保持 28px 状态行高度，展开不移动同排元素。
- 用量、模型、推理、设置共用锚定定位，在空间内选择上下方向、限制视口边界，原生 top layer 避免聊天容器裁切。
- Escape 或外部点击关闭弹层；用量 Escape 关闭后恢复触发按钮焦点。模型键盘浏览不直接更改选中模型。
- 未报告用量保持未知；模拟值不计为真实消耗。模型名保留自然语言斜杠，完整名称可查看。
- 浮栏附件、模型、设置、发送/停止同一行，32px 高度；模型名可省略，发送入口保持可见。

## 紧凑布局

按容器宽度重排。紧凑布局仍显示当前工具，Agent 对话为正文和输入保留高度；参考面板关闭后恢复原视图。窄看板使用网格，空列不强制撑满视口。代码、终端和长路径在各自区域滚动。
