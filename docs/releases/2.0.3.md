# Yukinal 2.0.3

2026-10-28 正式发行。应用版本统一为 `2.0.3`；Python Agent 继续独立使用 `0.1.0`。

## 本版变化

- 修复 Python Agent 实机验收发现的阶段判断、审计终态、只读健康检查、审批等待耗时、审批默认值及拒绝结果问题。
- 修复持久任务/计划的步骤结算、恢复和任务范围绑定；执行计划按保存的工具范围与审批状态运行。
- 为 Windows 桌面宿主嵌入 Yukinal 图标资源，主窗口和独立工作页窗口都设置小/大图标，并使用稳定的 Windows AppUserModelID。NSIS 快捷方式与宿主共用同一 ICO 文件。
- 为 `server.exec` denylist 增加独立 host 配置路径；策略在 SSH 派发前检查，配置无效时 fail closed，同时保留桌面 SSH autoconfig。
- README、发行说明与运行时版本来源统一到 `2.0.3`。

## 验收

Computer Use 验证了真实只读工具调用、`server.info` 计划步骤成功结算并在桌面重启后恢复、待审批操作自然过期且未执行，以及 host denylist 与桌面 autoconfig 联合工作。任务/计划持久恢复和结构化回复组件另有原生窗口与回归测试证据。

本地 `pnpm check` 包含原生 CTest、Python Agent、控制平面、桌面测试、UI 生产构建、sidecar smoke、文档链接、发布卫生和秘密扫描。三平台安装包、完整门禁和安装/卸载 smoke 由本版 GitHub Actions 发布工作流完成；只有工作流成功后，以下 Release 才会包含正式资产。

## 下载与校验

正式 Windows NSIS（`.exe`）、macOS Intel DMG（`.dmg`）与 Debian Linux（`.deb`）安装包，以及清单和 SHA-256 校验文件，见 [GitHub Release v2.0.3](https://github.com/Bad0RANG3/Yukinal/releases/tag/v2.0.3)。

## 限制

当前 Computer Use 和真实 Provider/SSH 证据只覆盖已配置的一台服务器。真实多目标并行/长时压力、安装版 GUI 的人工验收、代码签名与 macOS 公证尚未完成。安装包未签名，macOS 应用未公证；不要把当前证据扩展为未测组合均已通过。
