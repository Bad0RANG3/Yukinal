# Yukinal 2.0.1

2026-10-27 正式发行。项目负责人已确认 Agent 能力验收合格，同意发布；明日继续界面体验优化。

## 本版变化

- 文件、终端、日志、服务四按钮直接切换主界面，移除额外标签页、新增、分栏和返回对话操作；Agent 在右侧浮栏持续交流。
- 切换工具保留终端、目录、日志筛选与草稿；切换目标后工具跟随服务器，原终端可恢复。
- 修复 Token 展开跳位、按钮对齐、模型/设置菜单裁切、紧凑输入遮挡和窄看板布局。
- 过滤混入其他服务器的操作记录，修复模型名误截断。
- 收拢 Agent 工具循环、值守和第五轮审计修复，包含退出状态、未知结果及审批/可访问性呈现；纳入此前 Provider 冷启动修复。
- 重写中英文入口、交互和发布文档。应用版本 `2.0.1`，Python Agent 独立包版本 `0.1.0`。
- 更新 Vite `8.2.4` 与 Zod `4.6.6`，修复当前依赖安全审计告警。

## 下载与校验

资产包含 Windows NSIS（`.exe`）、macOS Intel DMG（`.dmg`）与 Debian Linux（`.deb`），以及平台清单、载荷校验和与总 `SHA256SUMS.txt`。正式 publish 仅在三平台门禁、构建和安装/卸载 smoke 成功后运行。

## 验收与限制

Agent 验收依据为负责人于 2026-10-27 的明确确认。今晚 UI 桌面测试 622 项通过，最后一轮针对性回归 47 项通过，类型检查和生产构建通过；模拟浏览器检查三种尺寸与连续操作。模拟用量不代表真实消耗。

安装包未签名，macOS 应用未公证。本次未新增逐端点、三平台 GUI 拖放和升级组合的公开记录；完整任务/计划恢复仍有后续工作。证据范围见仓库 `docs/release.md`，不把历史 CI 和 mock 结果延伸为所有环境均已覆盖。
