## 坑与约定

- **永远不要改已应用的迁移**：`MIGRATIONS` 只能追加；改了会让旧库的备份/回滚语义和 `user_version` 失真。
- **新增 wire error code**：必须同时改 `error-taxonomy.json` 与两侧 enum，否则 `errors.test.ts` / `error_taxonomy.rs` 会红（这是刻意的）。
- **错误类别的 anchor**：ADR 0077 在 `adr.md` 里，文档链接锚点由 `scripts/check-docs-links.mjs` 校验。
- **副本会保留**：成功升级后 `.pre-migration.bak` 仍在，作为上一版本恢复点；下次升级覆盖。
- **恢复内部函数不能从 UI 直接调**：命令层的 `State<'_, AppState>` 包装负责 IPC 校验；宿主生命周期用 `&AppState` 版本。
- **`.claude/` 是本地 worktree**，已 ignore；如果看到它出现在 `git status`，说明 ignore 被改坏了。
